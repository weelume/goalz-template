# 验收记录

本模板实现 45 个页面、90 条中英文路径，包含六种课程、六名教练、六名球员、六篇文章、六项赛事以及列表和通用页。默认中文；英文 /en；切换保留查询及锚点。所有表单仅本地校验，不发送或保存。

在本机 WSL Linux 文件系统，Node 24.16.0、pnpm 9.15.4，已执行冻结安装、typecheck、lint、test 和生产 build。具体最终源码摘要与命令结果见 ../reports/verification.json；报告状态区分工程可运行与视觉完整性。

内置浏览器已检查 PC 1440×1000、iPad 834×1180、H5 390×844，首页/课程/博客/联系各一张。JPEG 实际解码尺寸分别 1430×993、824×1166、380×822，转为 WebP 时不放大或调整尺寸。协议 0.2.0 screenshot.device 尚无 tablet 值，市场 JSON 登记 PC/H5 八张；平板四张同样保存在 assets，运行时元数据登记 tablet 及真实尺寸。

320px 补测中英首页、课程、英文联系、联赛详情和课表，没有横向溢出。菜单/FAQ/语言切换/演示表单/视频/滚动位置恢复已实际操作。视频、导航等 debug 日志为单行结构化上下文，不记录表单值；本次采样未捕获控制台 warn/error。
